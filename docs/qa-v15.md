# v1.5 — Four origins

New games select Seiji, Ophelia, Marin or Gabriel. Each starts alone, with a unique opening scene, lore in the quest journal, and a real map spawn (Pátio 14/12, Domo 12/12, Porto 18/10, Mata 12/10). These origins converge on the existing investigation led by Beatriz.

Recruitment: Ophelia after accepting Beatriz's investigation; Seiji after reading the library record; Marin at camp; Gabriel after the eastern ash-wolf encounter. The first recruit fills the empty second slot. Later recruits enter the reserve. Recruited heroes disappear as map NPCs. Solo rendering, dialogue portraits, combat order, field skills, and saves support one or two active heroes. Legacy paired saves remain compatible. The Pira entrance now requires completion of the initial chapter to protect early origin routes.

Validation: 1,108 automated checks passed across baseline, progression, expansion, echoes, v1.4 and origins suites. TypeScript passed. Browser QA used the managed preview: desktop 1363x936, mobile iframe 390x844 and 320x640. Checked selection and identity, Marin's Porto opening and solo roster with locked allies, Gabriel's Mata spawn, Ophelia's Domo opening, reset confirmation, existing-game continuation, and mobile CTA reachability. Physical devices were not tested. All temporary QA routes removed before the build. Existing music and public-by-link audience preserved.
